# Parameteric2DEaveDetail

An interactive, browser-only 2D constraint laboratory for studying roof eave authoring.

The lab includes mutually exclusive structural modes for:

- Rafter with birdsmouth bearing
- Raised-heel truss
- Cantilevered raised-heel truss
- Common truss

All geometry is generated in the browser and no data is stored.
